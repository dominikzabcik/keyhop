## Learned Workspace Facts

- Keyhop V2 (big-bang 2.0) is being built on the long-lived `v2` branch per the approved plan in `~/.claude/plans/pasted-content-id-7e83-cht-l-bych-prancy-floyd.md`: ~12 weeks, milestones M1 tracker core → M2 UI per `design/keyhop-v2/index.html` → M3 social + live cloud → M4 optimizer/coaching/growth → M5 parity + docs + launch. Cloud changes stay on `main` (backwards compatible, deployed continuously). Key decisions are recorded in `docs/adr/0001`–`0003` and the glossary in `CONTEXT.md`.

- This checkout is Keyhop (`github.com/dominikzabcik/keyhop`): a Swift macOS app (target `Keyhop`), the `keyhop` CLI, and the cloud site at keyhop.app. The directory is named switchr.
- Team day is `/t/<team>/day` (older days use `/day/YYYY-MM-DD`). Machines opt in with `keyhop work add`, `keyhop work on`, and `keyhop work subjects on`. Only commits the person authored count, merge commits are excluded, and each day is rewritten on sync so rebases are not counted twice. Task titles come from commit subjects. The Mac window shows the same day under Teams. The leaderboard and the season rank efficiency (commits per million tokens, past a one-million-token floor) by default, inside plan-based divisions (free, pro, max) that the app reports from its logins' plans; tokens, API value, requests, commits, lines and cache hit stay as metrics, and tiers still follow season tokens. Uploads are verified server-side (requests fit tokens, API value fits a list-price band, cache reads fit tokens). Live sharing is opt-in (`keyhop cloud live on`, Settings → Cloud): today's per-tool totals every ninety seconds to `POST /api/live`, kept with a TTL and swept hourly; a team day marks a person live under three minutes. `keyhop cloud show-data` and Settings → Cloud show every payload before it goes.
- Usage in the window, CLI, JSON, and MCP groups by account, tool, and model. Token totals cover Claude Code, Cursor, Codex, Gemini CLI, OpenCode, and Pi. Copilot, Windsurf, and Codebuff expose limits only, because they do not leave a complete model-token transcript.
- Jev is the Typesafe screen review in CI. Its judgements are reported and do not fail the build.
- A linked account has one lifetime pet, computed from synced daily totals and not stored. Stages are Speck, Hatch (1M tokens), Frame (50M), Bulk (500M), Mass (5B), and Monument (25B). The dominant measured tool sets the markings, the streak sets the pose, and commits set the build. A public profile shares it at `/u/<login>/pet.svg`. The same shapes are painted on the profile, the team page, Overview, the Mac menu, and the iOS season screen. The status icon still shows limits.
- The Mac window is one HTML page served by a loopback server and assembled from `Sources/Keyhop/Dashboard/Page/` (stylesheet, shell, one script file per section); it builds and runs on Linux, so `keyhop dashboard --sample` feeds the window e2e suite and `checks/run.mjs --app` anywhere. The window and keyhop.app share the Keyhop 2.0 world: one warm charcoal ramp, color is state only, paper-on-ink actions, brand blue only in the K mark, the focus ring and the selection; every overlay tint reads from the `--on` ink hue, never a literal white.
- The window has five places: Home (the field as a wallpaper, attention list, in-use logins, week figures), Limits (Accounts folded in; the pooled forecast from `GET /api/quota`, also `keyhop forecast` and MCP `keyhop_forecast`, built by `QuotaReport` in `Core/Quota.swift` from the limit samples kept 8 days), Usage, Insights (Coach, Plans, Budgets as tabs) and Community (Leaderboard, Season, Teams, Profile as tabs). Section ids and `#accounts` links still work; `GROUPS` in the page script maps sections to places. The backdrop scene shows only in Home's wallpaper unless Settings › Appearance › Show on is Everywhere.
- Plans (`keyhop plans`, window section) prices each login's plan at list against the month's API value and the week's window peaks from the limit samples; Coach (`keyhop coach optimize|compare|yield`, window section) reads cache hit, premium-model share, the heaviest sessions, this month against last, and tokens and API value per commit and per merge from the counted repositories. Both are local; nothing is sent. Teams can post a daily digest to a Slack or Discord incoming webhook (team page, owner only, the hourly cron at the chosen UTC hour); `/u/<login>/wrapped` wraps a year from the daily totals.
- `native/` is a GPUI Kit (Rust) spike of the Mac window, a client of the same local API (`keyhop dashboard --no-open --json`) the HTML window reads; the Swift core stays the only code that touches logins and usage. `cargo test` and `cargo run -- --sample` in `native/`. The nightly workflow (on main) builds `v2` for macOS on every push to `v2` and bundles `keyhop-native` beside Keyhop.
